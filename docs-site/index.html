Install

BLACKBOX is a single static binary. No Python, no Node, no runtime needed on the host.

# Linux x86_64
curl -L https://github.com/blackbox-project/blackbox/releases/latest/download/blackbox-linux-x86_64 -o blackbox
chmod +x blackbox
sudo install -m755 blackbox /usr/local/bin/blackbox

# macOS ARM64
curl -L https://github.com/blackbox-project/blackbox/releases/latest/download/blackbox-macos-aarch64 -o blackbox
chmod +x blackbox
# First run may need: xattr -d com.apple.quarantine blackbox
sudo install -m755 blackbox /usr/local/bin/blackbox

# Windows x86_64 (PowerShell)
irm https://github.com/blackbox-project/blackbox/releases/latest/download/blackbox-windows-x86_64.exe -OutFile blackbox.exe
# Move to a folder on PATH

Then verify: blackbox doctor

cargo install blackbox-runtime
# Or from source:
git clone https://github.com/blackbox-project/blackbox
cd blackbox
cargo build --release
# Binary at target/release/blackbox
pip install blackbox-runtime
# Requires Python 3.9+ on the host running the CLI
# Package recipients never need Python

Five-Minute Quickstart

Create, pack, and run your first BLACKBOX package

Initialize a project

blackbox init hello cd hello

Pack into .blackbox

blackbox pack

Run locally

blackbox run hello.blackbox

Ship it

# Send hello.blackbox via # USB, email, HTTP, etc.

Recipient runs it

blackbox run hello.blackbox

Why BLACKBOX?

Not a container. Not a package manager. A portable appliance format.

📦

Single File Distribution

One .blackbox contains everything: code, runtime, dependencies, permissions, interface. Copy it anywhere.

🔒

Permission-First

Packages declare filesystem, network, and process access. Defaults deny everything. Recipient approves on first run.

📦

Content-Addressed Storage

Layers deduplicated by SHA-256. Ten apps using Python 3.12 + NumPy share one copy on disk.

🔄

Reproducible Builds

Identical source + lockfile → byte-identical package. Deterministic ZIP with fixed timestamps.

🌐

Offline Forever

No registry, no accounts, no tokens. The file is the product. Works air-gapped.

⚙️

Multi-Runtime

Python, Node.js, WASM, Rust, native binaries. Add new languages via provider plugins.

Sealed research environment. Pip dependencies pinned by hash (Jinja2, MarkupSafe).

# → output/report.html, metrics.json

🦀 Native / Rust

Compiled binary IS the runtime. Cross-compiles to any target at pack time.

Inspecting Packages

Every .blackbox is a documented, inspectable archive

CommandDescription
blackbox inspect pkg.blackboxManifest, layers, permissions, signature
blackbox verify pkg.blackboxChecksums + signature verification
blackbox unpack pkg.blackbox ./peekExtract all layers for manual inspection
blackbox audit pkg.blackboxStatic security scan before running
blackbox explain pkg.blackboxHuman-readable permission summary
blackbox diff a.blackbox b.blackboxCompare two packages at checksum level

Trust & Signing

Optional Ed25519 signing + X25519 sealed secrets

Create Keys

blackbox keygen lab \
  --publisher "Research Lab X"

Sign Package

blackbox sign pkg.blackbox \
  --key lab

Trust Publisher

blackbox trust lab.pub.pem \
  --publisher "Research Lab X"

Seal Secrets

blackbox seal pkg.blackbox \
  --secrets .env \
  --to lab.seal.pub.pem

Encrypt Package

blackbox encrypt pkg.blackbox \
  --to recipient.seal.pub.pem

Verify

blackbox verify pkg.blackbox
# → Signature: VALID - trusted publisher

Manifest Reference

The blackbox.yaml contract — strict validation at pack time

format_version: "1"
name: "my-app"
version: "1.0.0"
description: "What this package does"
publisher: "Your Name"

runtime:
  type: "python"        # python | node | native | wasm | rust | composite
  version: "3.12"       # pinned version
  target: "x86_64-unknown-linux-gnu"
  targets: []           # optional: multi-target fat package

entrypoint:
  command: "python"     # must be "python" for python, "node" for node, "./bin/app" for native
  args: ["main.py"]

permissions:
  filesystem:
    read: ["./input", "./config"]
    write: ["./output", "./data"]
  network:
    enabled: true
    allow: ["api.example.com", "*.githubusercontent.com"]
  process:
    spawn: false

limits:
  memory_mb: 512
  cpu_percent: 50
  max_processes: 10

entrypoints:            # optional subcommands
  serve:
    command: "python"
    args: ["server.py"]
  migrate:
    command: "python"
    args: ["migrate.py"]

environment:
  variables:
    LOG_LEVEL: "info"
    API_TIMEOUT: "30"

interface:
  type: "web"           # cli | web | gui
  port: 8765

requirements: "requirements.txt"  # or package.json for node
