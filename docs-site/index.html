Send a program that installs nothing.

Blackbox puts an application, its runtime, its dependencies and the permissions it needs into a single file. The person receiving it runs that file. Python, Node and everything else arrive inside it.

Get Blackbox See what's in the file

One file, and everything it needs to run.

A blackbox is not a script that expects a machine to already be set up. It carries the machine. Nothing on the receiving computer is consulted, installed or upgraded.

Runtime

Python, Node.js, WebAssembly, Rust or your own compiled binary. Fetched from a hash-pinned upstream build, or built while packing.

Dependencies

pip and npm resolved for the machine you are targeting, then recorded by version and checksum in the lockfile.

Permissions

Files, network and processes are denied unless the manifest asks for them. You are shown the list before the first run.

Interface

A command, a local web page or a window, plus any named subcommands the package exposes.

Secrets

Keys and tokens can be sealed to one recipient and opened only while the app runs.

Signature

A publisher signs the contents. If a single byte changes afterwards, the package stops running.

Making one takes three commands.

1

Describe the application

One small blackbox.yaml names the runtime, the entrypoint and what the app is allowed to touch.

2

Run blackbox pack

Blackbox resolves the dependencies, verifies them, and writes a package whose bytes depend only on the source and the lockfile. Pack twice and you get the same file.

3

Hand over the file

Mail it, put it on a stick, upload it to a paper's supplementary material. It runs the same way on a laptop, a server or a machine with no network at all.

Install it on the machine you pack from.

The people you send packages to do not install Blackbox unless they want to run one from a terminal or look inside it. The desktop app and the command line tool are both on the download page.

You can look inside before you run it.

A package is an ordinary archive. These commands read it, check it and take it apart.

CommandWhat it tells you
inspectThe manifest, the layers, the permissions and who signed it.
verifyWhether every checksum and signature still matches.
auditWhat the package would be able to reach, found by reading it rather than running it.
explainThe permission list in ordinary words.
unpackEvery layer on disk so you can read the code yourself.
diffWhich members changed between two builds.
sbomA CycloneDX or SPDX inventory taken from the lockfile.
cacheHow much is stored locally, and whether any of it has rotted.
doctorWhat this machine can enforce: the platform jail, the runtime shims, the limits.

Signed by a publisher, or sealed to one person.

Signing

Keys are Ed25519. You pin a publisher once, by fingerprint, and after that their packages are trusted by name.

$ blackbox keygen lab --publisher "Research Lab X"
$ blackbox sign   report.blackbox --key lab
$ blackbox trust  lab.pub.pem --publisher "Research Lab X"
$ blackbox verify report.blackbox

Sealing

Secrets travel inside the package, encrypted with X25519 and AES-256-GCM, and are opened only with the recipient's private key at run time.

$ blackbox seal    report.blackbox --secrets .env --to lab.seal.pub.pem
$ blackbox encrypt report.blackbox --to lab.seal.pub.pem

An unsigned package stops and shows its full permission list before it runs. A signed package whose contents changed will not start at all.

Three examples you can pack in a minute.

datasift

A CSV cleaning tool with a local web page. Uses nothing outside the Python standard library, which is the point: the recipient installs nothing, not even for the package itself.

$ cp -r examples/datasift myapp
$ cd myapp && blackbox pack
$ blackbox run datasift.blackbox
# datasift is live at http://127.0.0.1:8765

research-repro

A report rendered by pinned versions of Jinja2 and MarkupSafe on an interpreter downloaded and verified on the reviewer's own machine. Send it with the paper.

$ cp -r examples/research-repro repro
$ cd repro && blackbox pack
$ blackbox run research-repro.blackbox
# output/report.html, output/metrics.json

wordcount-node

Node.js 22 with npm dependencies. The official distribution from nodejs.org, pinned by version and checksum at pack time.

$ blackbox init wordy --template node
$ cd wordy && blackbox pack
$ blackbox run wordy.blackbox
